FUNDAMENTOS

Conceptos básicos

La programación puede compararse con la estrategia de un equipo de fútbol: primero analizamos la situación, después tomamos decisiones y finalmente obtenemos un resultado.

01

Variables

Las variables almacenan información que puede cambiar durante la ejecución de un programa.

goles = 3
02

Tipos de datos

Permiten identificar qué tipo de información estamos almacenando dentro de una variable.

equipo = "Colombia"
03

Operadores

Permiten realizar operaciones matemáticas, comparaciones y operaciones lógicas.

goles + 2
04

Algoritmos

Son instrucciones organizadas paso a paso para solucionar un problema determinado.

Inicio → Juego → Gol

DESARROLLO

Programar también es jugar en equipo

La programación permite transformar problemas reales en soluciones mediante instrucciones que pueden ser interpretadas por un computador.

En el fútbol ocurre algo similar. Un equipo analiza la situación, toma decisiones y sigue una estrategia para conseguir un resultado.

Por eso podemos utilizar situaciones futbolísticas para comprender variables, condiciones, operadores y algoritmos.

CONCLUSIÓN

La lógica es el comienzo

El aprendizaje de la lógica de programación permite desarrollar habilidades para analizar problemas y construir soluciones mediante algoritmos.

Así como un equipo de fútbol necesita estrategia, comunicación y organización para conseguir un gol, un programa necesita lógica, instrucciones y datos para obtener un resultado.

"Una buena estrategia gana partidos; una buena lógica construye programas."
